# CSS Gradient Generator & Studio — Gamility Tools

A modern, visual, and interactive CSS gradient design studio. Features multi-stop color blending for linear, radial, and conic gradients, angle controllers, a curated gallery of designer presets, random harmony generation, cross-browser CSS code generation, and high-resolution PNG wallpaper export.

---

## 🌟 Features & Highlights

- **🎨 Multi-Stop Gradient Slider:**
  - Click anywhere on the visual gradient track to add new color stops.
  - Drag color stops smoothly between 0% and 100%.
  - Integrated color picker and HEX input with stop deletion.
- **🔄 3 Core Gradient Models:**
  - **Linear Gradient:** Interactive angle controller (0°–360°) and 8 directional quick-aim shortcut buttons.
  - **Radial Gradient:** Circle vs Ellipse geometry with customizable focal origins.
  - **Conic Gradient:** Modern pie-chart and angular color blend mode.
- **✨ 16+ Curated Designer Presets:** Instant access to trending palettes including *Neon Cyberpunk, Sunset Blaze, Ocean Breeze, Purple Velvet, Emerald Aurora, Solar Flare,* and *Midnight Obsidian*.
- **🎲 Random Harmony Generator:** 1-click generation of stunning color stops with balanced chromatic harmony.
- **📱 Real-Time UI Component Preview:** Inspect your gradient applied to mock web elements (glassmorphism card, call-to-action button, typography header).
- **📋 Cross-Browser Code Export:**
  - Standard CSS: `background: linear-gradient(...);`
  - Fallback solid background color.
  - SVG linear gradient markup export.
  - High-res PNG image download (generate custom wallpapers and web assets).
- **🔒 100% Client-Side Privacy:** Zero server transmissions. All rendering and export happens inside your browser's local memory.

## 🚀 Quick Start

### Local Preview
Open `index.html` directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve via any static HTTP server:
```bash
npx serve .
```
